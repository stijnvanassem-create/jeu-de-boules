# Jeu de Boules

Mobiele scorekeeper voor een americano jeu de boules-toernooitje met vier spelers.
Eén HTML-bestand, alles in localStorage, werkt offline na de eerste keer laden.

- **Foto's:** vervang `players/sos.jpg`, `players/dollo.jpg`, `players/tobihash.jpg` en `players/mrneus.jpg` (vierkant werkt het best). Zonder foto verschijnt een gekleurde cirkel met de eerste letter.
- **Reset:** Start-tab → *Reset toernooi*. Het all-time klassement blijft staan; *Wis ook de historie* wist dat apart.
- **Icons:** `python3 icons/make_icons.py`
